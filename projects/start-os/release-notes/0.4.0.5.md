**0.4.0.5 can prepare a drive for backups and fixes command input through `package attach`.**

## Highlights

- **Format a backup drive from StartOS.** `System > Create Backup` offers "Format a drive", which erases a connected drive and leaves it with a single Btrfs partition ready for backups.
- **Piped commands finish when their input ends.** Commands such as `cat` run through `package attach` receive EOF from piped or redirected stdin and exit normally.
