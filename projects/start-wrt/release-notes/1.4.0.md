**StartWRT 1.4.0 lets one Ethernet port carry every security profile to a managed switch, so each of the switch's ports can sit on a profile of its own.**

## Important

- **A managed switch is only as safe as its own configuration.** Every profile reaches it as a tagged VLAN, including Admin. Set the switch up before you connect it, keep its management password private, and follow the guide's rule of never deleting a VLAN that is some port's PVID. The [Managed switch](https://docs.start9.com/start-wrt/managed-switch.html) guide walks through it, and the TP-Link Easy Smart walkthrough covers that family of switches step by step.
