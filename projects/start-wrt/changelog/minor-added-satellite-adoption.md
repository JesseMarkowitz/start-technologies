- **A satellite router can be adopted from the Core over the cable.** A router
  in the satellite role that has not yet joined a Core answers the Core's
  announcement on its WAN port and appears in the Core's candidate list. Adopting
  it takes the satellite's sticker Wi-Fi password, or the adoption code a board
  without one shows, typed at the Core; the password never crosses the cable.
  Both routers then bring up their first tunnel with the keys the exchange pinned.
  Five wrong attempts pause adoption for a minute on either side.
